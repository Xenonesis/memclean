Upcoming Features

Planned development phases for MemClean. Status tags reflect current implementation state on master.

Competitive Network Latency Tweaker

TCPNoDelay=1, TcpAckFrequency=1, disable Windows 20% network throttling. Atomic registry backup with one-click rollback.

GPU VRAM Manager

WDDM 2.1+ D3DKMTTrimProcessCommitment + DXGI multi-GPU telemetry to decommit unreferenced GPU texture buffers on background app exit.

API: WDDM driver thunkTarget: VRAM reclaim

CPU Affinity & Core Parking

Intel/AMD P-core vs E-core detection via GetLogicalProcessorInformationEx. Lock games to P-cores; clamp background bloat to E-cores.

API: core topologyTarget: P/E core affinity

Hard Page Fault Telemetry

NtQuerySystemInformation(2) real-time disk page-fault reads to diagnose gaming frame-rate stutter root causes.

API: NT perf class 2Target: stutter detection

Zero-Injection Game HUD Overlay

Always-on-top click-through micro-overlay: live FPS, frame-time, RAM, VRAM, 0.5 ms timer resolution. Ctrl+Shift+O toggle. Anti-cheat safe.

API: layered windowTarget: overlay HUD
