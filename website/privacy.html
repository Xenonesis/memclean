Privacy Statement

Privacy & Security

MemClean respects your privacy. No telemetry, no network calls, no account, no tracking.

Zero Telemetry

MemClean does not collect, transmit, or store any usage data, telemetry, or diagnostics. Nothing leaves your machine.

No Network Access

The binary makes zero outbound network connections. All memory operations are local Win32/NT kernel calls on your PC only.

Local-Only Config

Configuration is stored locally at %APPDATA%\MemClean\config.toml. It is never uploaded or synced to any server.

No Account Required

No registration, login, email, or personal information is ever requested.

Open Source (MIT)

Full source is public on GitHub. You can audit every line, compile from source, and verify the binary yourself.

No Third-Party SDKs

No analytics, crash reporting, advertising, or telemetry SDKs. The only dependency is windows-sys for Windows API declarations.

Permissions & Privileges

MemClean requests administrator elevation solely to acquire SeProfileSingleProcessPrivilege and SeIncreaseQuotaPrivilege, required for NT kernel memory list operations (MemoryPurgeStandbyList, MemoryFlushModifiedList). These privileges are used only for memory reclamation — never for data collection.

Data Retention

MemClean does not retain any user data. The only persistent file is your local config.toml, which you control completely. Delete it anytime to reset all settings.
