Troubleshooting & Common Issues

Solutions for UAC elevation, administrator privileges, SSD vs HDD behavior, config location, and other common MemClean questions.

The portable edition (memclean.exe) requires administrator rights to purge NT kernel memory lists. If you run it directly without the zero-UAC scheduled task, Windows shows a UAC prompt.

Fix: Use the Setup Installer, which registers a Task Scheduler logon task with TASK_RUNLEVEL_HIGHEST — MemClean launches silently at login with no UAC dialog.
Purging standby/modified memory lists requires SeProfileSingleProcessPrivilege and SeIncreaseQuotaPrivilege. If elevation fails, kernel calls return access-denied.

Fix: Run MemClean as administrator, or ensure the zero-UAC scheduled task is installed (Setup Installer only). Verify you are on Windows 10/11 64-bit.
MemClean stores its configuration in:
%APPDATA%\MemClean\config.toml

Typical path: C:\Users\<YourName>\AppData\Roaming\MemClean\config.toml

Reset config by closing MemClean and deleting config.toml; defaults are regenerated on next launch.
MemClean detects your system drive type via the IOCTL_STORAGE_QUERY_PROPERTY seek-penalty query and applies storage-aware defaults:

SSD: flush_modified = false (avoid write wear), timer off / 300s, threshold 85%, trim_working_sets = true
HDD: flush_modified = true, timer off / 300s, threshold 80%, trim_working_sets = false (avoid stall)

Manual settings always override — the button only suggests defaults.
Yes. On HDD, MemClean defaults to flushing modified pages to disk (helps HDD cache) and disables working-set trim to avoid seek stalls. The auto-clean threshold is set to 80%. Standby purge remains safe on both SSD and HDD.
Yes. The Game HUD is zero-injection — no DLL hooks, no process memory modification. It is an always-on-top, click-through overlay only. The memory cleaner uses documented and undocumented NT kernel APIs that do not inject into game processes.
In versions before v1.1.2, auto-clean only purged the standby list, which does not lower used% because standby pages count as "available." Since v1.1.2, the full purge pipeline runs on threshold breach, including modified-list flush and working-set trim, so RAM% actually drops.
Setup Installer: Use "Add or Remove Programs" (Apps & Features) → MemClean → Uninstall. This removes the binary, the scheduled task, and registry entries.

Portable: Delete memclean.exe and optionally %APPDATA%\MemClean\config.toml. No registry changes are made.
The zero-UAC startup relies on the Windows Task Scheduler logon task, installed by the Setup Installer. If you use the portable edition or removed the task, MemClean won't start silently at login.

Fix: Re-run the Setup Installer, or manually create a Task Scheduler task with TASK_RUNLEVEL_HIGHEST triggered at logon.

Still stuck? Open an issue on GitHub with your Windows version, RAM size, and the steps to reproduce.
