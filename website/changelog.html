Release History

Changelog

MemClean release history. All versions are built with windows-sys 0.59 — pure Win32, zero external dependencies.

v1.1.3Nov 17, 2026
  • feat(ui): Add "Best for Your Device" button — auto-detects SSD vs HDD via IOCTL_STORAGE_QUERY_PROPERTY seek-penalty query and applies storage-aware defaults (SSD: no flush_modified, timer off, threshold 85%; HDD: flush_modified on, threshold 80%).
  • feat(core): New src/core/disk.rs drive-type detection module with DriveType enum and detect_system_drive_type().
  • feat(config): Add apply_device_defaults(is_ssd) to AppConfig with sanitize() validation.
  • build: Add Win32_System_IO and Win32_System_Ioctl to windows-sys features.
  • docs: Website "Device Profile" telemetry card + README bullet; version bump to 1.1.3.
v1.1.2Nov 16, 2026
  • fix(tray): Auto-clean threshold now runs the full perform_clean pipeline (standby + working-set trim) so RAM% actually drops; added auto_clean_enabled master gate and cleaned_this_tick de-dupe; tray status reports freed MB.
  • feat(ui): Polished owner-draw button hover feedback — animated background + border on tabs and Apply button via TrackMouseEvent(TME_LEAVE) + WM_MOUSELEAVE.
  • fix(ui): Repaired corrupted src/ui/dialog/mod.rs via full rewrite; clean release build, zero warnings.
  • perf: Config threshold reverted to 78; auto timer disabled (60s standby purge too aggressive on SSD).
  • release: Tag v1.1.2 pushed; deployed and live-verified (RAM 80% → 66%, freed 1557 MB).
v1.1.1Oct 30, 2026
  • feat: Initial public release — pure Rust Win32 memory optimizer.
  • 5-tier NT kernel purge: Standby, low-priority standby, modified flush, file cache trim, filtered working sets.
  • ISLC standby cleaner: Dual-condition purge (high standby + low free).
  • Microsecond timer resolution: 0.5 ms scheduler lock via NtSetTimerResolution.
  • Kernel page combining: NtSetSystemInformation(130) Copy-On-Write de-duplication.
  • Segmented GDI memory bar: Visualize In-Use, Standby P0–P7, Modified, Free pools.
  • EcoQoS: Windows 11 efficiency-mode toggle for background processes.
  • Smart Game Guard: Foreground-process exemption during working-set trims.
  • Zero-UAC startup: Task Scheduler TASK_RUNLEVEL_HIGHEST logon task.
  • Dual-mode binary: Interactive tray daemon + headless CLI (--status --json).
  • Global hotkey: Ctrl+Alt+M purge with tray notification.
  • Live process view: Top consumers, per-process Trim and EcoQoS.

Source: GitHub Releases — assets include MemClean_Setup.exe (Inno Setup, SHA-256 verified) and memclean.exe (portable).
