Scriptable Interface

Headless Command-Line Reference

Embed MemClean into batch files, PowerShell scripts, game launchers, or CI runner environments. MemClean uses the Win32 AttachConsole() API — when invoked from Command Prompt or PowerShell with arguments, it executes headlessly, emits structured stdout, and returns standard exit codes (0 for success, non-zero for failure).

Basic Usage

memclean.exe --status

Requires administrator privileges (auto-elevated via Task Scheduler zero-UAC logon task).

FlagAliasDescriptionOutput
--status-sPrints current RAM usage, standby cache, modified list, and working-set breakdown.Human-readable text
--clean-cRuns the full 5-tier purge pipeline (standby, low-priority standby, modified flush, file cache trim, filtered working sets).Freed MB summary
--network-nApplies competitive low-latency TCP tweaks (TCPNoDelay, TcpAckFrequency) with atomic rollback backup.Before/after registry values
--vram-vTriggers WDDM GPU VRAM decommitment across background processes.VRAM reclaimed MB
--cpu-pLocks scheduler timer resolution to 0.5 ms and unparks CPU cores.Timer resolution ms
--telemetry-tEmits live memory telemetry: in-use, standby P0–P7, modified, free pools.Tabular telemetry block
--hud-hToggles the zero-injection Game HUD overlay (Ctrl+Shift+O). Anti-cheat safe, click-through.HUD state (on/off)
--json-jEmits machine-readable JSON output for integration with Rainmeter, monitoring scripts, or dashboards.JSON object
--timer-res 0.5-rSets global Windows timer resolution (0.5 or 1.0 ms) for minimum input latency.Resolution applied
--apply-device-defaults-dDetects SSD vs HDD via seek-penalty IOCTL and applies storage-aware config defaults (v1.1.3).Detected drive + applied settings
--set-threshold <n>-TSets the auto-clean RAM threshold percentage (e.g. --set-threshold 80).New threshold value
--export-config-eExports current config.toml from %APPDATA%\MemClean\ to stdout.TOML document
--help-?Prints this help text and exits.Usage help

Exit Codes

CodeMeaning
0Success — command completed.
1General failure — insufficient privileges or kernel call error.
2Invalid arguments — unknown flag or malformed value.
3Elevation required — run as administrator.

JSON Output Example (--json --status)

"version": "1.1.3", "ram": { "total_mb": 16384, "used_mb": 13184, "available_mb": 3200, "used_percent": 80.5 }, "cache": { "standby_mb": 6140, "modified_mb": 1920, "free_mb": 2900 }, "timer_resolution_ms": 0.5, "device_type": "SSD", "flush_modified": false, "auto_clean_enabled": true, "threshold_percent": 85, "exit_code": 0}

PowerShell Automation Example

# Check RAM status $output = memclean.exe --status Write-Host $output # Run full purge if RAM > 80% $status = memclean.exe --json --status | ConvertFrom-Json if ($status.ram.used_percent -gt 80) { memclean.exe --clean; Write-Host "Purge complete" }

Note: All kernel operations (MemoryPurgeStandbyList, MemoryFlushModifiedList, SetSystemFileCacheSize) require SeProfileSingleProcessPrivilege and SeIncreaseQuotaPrivilege. MemClean acquires these automatically via token elevation.
